# Landline

Text or call the websites you already use.

## Problem

AI agents mostly reach software built for tech-savvy people. That's where MCPs and agent integrations show up first. The services average people depend on, like phone carriers, utilities, and pharmacies, haven't kept up. If their website is confusing, the user is stuck.

## What Landline does

Landline lets anyone use those sites by texting or calling an assistant. The user opens the Landline Chrome extension on a site they're logged into. They click "Connect to iMessage." From then on, they can text or call to check their plan, pay a bill, or make a change.

## How it works

The extension copies the site's login session to a cloud browser. An agent for that site works in that browser to carry out requests. One orchestrator handles the user's texts and calls, and passes each request to the right site's agent. Write actions need Face ID approval before they go through.

Built with Photon (iMessage and voice) and [Browser Use](https://browser-use.com).
